File: /assets/fonts/font-counter.woff

This file is the UNMODIFIED upstream binary of the 7-Segment font.
It is shipped byte-for-byte as delivered by VIC on 2026-10-16 (original name
7segment.woff), so the delivered artefact and the released artefact are the
same bytes and can be checked against each other.

  Font         : 7-Segment, Version 3.0 (family name "Segment7")
  Author       : Jan Bobrowski
  Source       : https://torinak.com/font/7-segment  (nameID 12 records the
                 older URL http://torinak.com/7segment, which redirects there)
  License      : SIL Open Font License, Version 1.1 (nameID 13 "SIL OFL";
                 the author's page states "License: SIL OFL (free)")
  sha256       : 86524d259042eb943fef6f00209cc0156433af74ff83d937f9b3ff14eb185b10
  Provenance   : this sha256 equals the upstream download
                 https://torinak.com/font/7segment.woff , so the delivered file
                 is the genuine original release, not a re-cut or a re-export.
                 Re-checked 2026-10-16 from the home Mac.

  Copyright    : the delivered binary carries NO nameID 0 (copyright) string.
                 Its own metadata names the author (nameID 9, Jan Bobrowski),
                 the source page (nameID 12) and the licence (nameID 13, SIL
                 OFL). The notice below is the licence text the font itself
                 declares; no copyright line has been invented for it.

  Coverage     : 112 code points, as delivered - NOT subset. Includes
                 U+0030-0039, U+0041-005A, U+0061-007A, U+0020, calculator
                 symbols and U+1FBF0-1FBF9 (segmented digits).
                 U+002F SOLIDUS ("/") is ABSENT from this font.
  Format       : WOFF 1.0 (TrueType outlines, unitsPerEm 1024), not WOFF2.
                 Safari and Chromium both load it locally over file://.

  In Word Kalliope this file is used by ONE element only: the machine's
  page-counter window (#page-counter, face "KalliopeCounter"). It is
  deliberately NOT part of --font-stack, so it can never reach the document
  grid, the paper, the print sheets or the data-grid capability guard.
  Because the font has no "/", the AA/BB separator is drawn by the next family
  in the counter's own stack (KalliopeLatin, which already contains U+002F).
