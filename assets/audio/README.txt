Kalliope — /assets/audio/
=========================

第一版本默认不提供任何音频文件。
程序必须支持 0 / 1 / 2 / 3 个文件，存在什么播放什么，不存在即静默忽略。

用户可自行加入（文件名固定）：

    sound1.mp3  =  ordinary keyboard key
    sound2.mp3  =  space
    sound3.mp3  =  return

要求：
  - 格式：MP3
  - 不要修改文件名
  - 建议短促（小于 150 ms），避免快速输入时互相截断
  - 音频是反馈层，任何播放失败都不得影响输入或程序运行

关于 Day 0 探针（测试后可清理）：
  当前目录下的 sound1.mp3 是探针使用的 1.6 秒合成静音文件
  （lame 编码，32 kbps / 44.1 kHz / mono）。
  它不是产品资产，测试完成后可以删除，或替换为你自己的音效。

  sound2.mp3 与 sound3.mp3 故意不存在，
  用于验证"缺失资产静默失败"这一行为。
