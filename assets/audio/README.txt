Kalliope — /assets/audio/
=========================

按键音目录。程序必须支持 0 / 1 / 2 / 3 / 4 个文件：
存在什么播放什么，不存在即静默忽略。

文件名固定，不要改：

    sound1.mp3  =  ordinary character key
    sound2.mp3  =  space, arrow keys, Page Up / Page Down, Home, End, Backspace
    sound3.mp3  =  return
    sound4.mp3  =  the sheet turning over   （不是按键：视窗真的换到另一张纸时响）

发行包内容（1.1.2）：

    槽1  sound1.mp3   263.4 ms  峰值 -2.5 dB   RMS -21.4 dB   字符键（主声，基准）
    槽2  sound2.mp3   211.0 ms  峰值 -6.0 dB   RMS -26.3 dB   空格 / 方向 / 翻页 / Home / End / 退格
    槽3  sound3.mp3  1046.9 ms  峰值 -6.0 dB   RMS -31.4 dB   回车
    槽4  sound4.mp3  1046.9 ms  峰值 -7.3 dB   RMS -27.3 dB   换下一页纸

四个都是 44.1 kHz 立体声 MP3、带 Xing 无缝头、**起音都在第 0 个采样**。
产品侧的三个新文件交付时都带 24 ms 编码器死区（与 sound1 原版同样的病），
入库时按同一处置切掉；原件留档在 Dev-Memo-1.1.2/_dev-audio/source/。
电平层级是产品侧裁定的：字符键为主，其余三槽依次压低 3.4 / 3.5 / 4.7 dB。

要求：
  - 格式：MP3
  - 不要修改文件名
  - 音频是反馈层，任何播放失败都不得影响输入或程序运行

关于时长与复音（1.1.2 起，此条已变更）：
  1.1.1 及更早的版本每个槽只有 1 个 <audio> 元素，每次击键都把它拨回 0 秒，
  所以快速输入时前一次的声音会被截断，当时因此建议素材短于 150 ms。
  1.1.2 改为复音播放，前一次声音会自己播完并与后一次叠合，
  所以槽3/槽4 这种 1 秒级的素材不再是问题。

  但复音有代价：`file://` 下走的元素池路线要占用媒体元素，数量按槽分配
  （见 app.js 的 AUDIO_VOICES = [4, 3, 2, 2]，四槽齐备共 11 个）。
  这不是随便定的：Safari 上挂到 18 个媒体元素时，浏览器会开始直接拒绝 play()，
  每一次拒绝就是一个「按了键却没声音」的键（实测占击键数的 15%）。
  换素材时若把时长大幅加长，请相应调低该槽的声部数。
